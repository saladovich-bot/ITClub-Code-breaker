# IT CodeBreaker — IT Club AAUP

Квиз в стиле Kahoot: PIN-код, таймер на сервере, переподключение, цветные фигуры на телефонах,
диаграмма ответов, лидерборд и подиум. Очки и выбывание — по правилам клуба.

## Структура

```
app.py                 сервер (вся логика игры)
requirements.txt
quizzes/               квизы в JSON — по одному файлу на квиз
static/                logo.png, музыка и картинки для вопросов
templates/
  index.html           вход: PIN + имя
  play.html            экран игрока (лобби, ответы, результаты, подиум)
  host.html            экран хоста / проектор
```

Старые `lobby.html` и `game.html` больше не нужны — их заменил `play.html`.

## Запуск на ноутбуке

```
pip install -r requirements.txt
python app.py
```

- Хост открывает **http://localhost:5000/host** на ноутбуке (подключённом к проектору).
- Игроки в той же Wi-Fi сети сканируют QR или открывают адрес, который показан на экране хоста, и вводят PIN.
- Музыка включается после первого клика по странице хоста (так требуют браузеры).
- Музыку сервер ищет сам в любой папке внутри `static/` по именам `lobby`, `question`,
  `heartbeat`, `podium_suspense`, `winner` (.mp3/.wav/.ogg/.m4a, регистр не важен).
  Если какого-то файла нет — на экране хоста в лобби появится жёлтое предупреждение.

Если телефоны не открывают страницу — разрешите Python в брандмауэре Windows/macOS для частных сетей.

## Правила (меняются в начале app.py)

| Настройка | По умолчанию | Что делает |
|---|---|---|
| START_SCORE | 100 | стартовые очки |
| WRONG_PENALTY | 20 | минус за неверный ответ или если не ответил |
| POINTS_PER_SECOND | 2 | правильный ответ = оставшиеся секунды × 2 |
| STREAK_BONUS | 0 | бонус за серию правильных (5 → +5, +10, +15…) |
| READ_TIME | 5 | секунд показывается только вопрос |
| DEFAULT_TIME | 30 | время на вопрос, если не указано |
| DEFAULT_QUIZ | it_basics | какой квиз выбран при создании игры |

Счёт ниже 0 — игрок выбывает и дальше только смотрит.

## Как писать квиз

Файл `quizzes/<любое_имя>.json`. Квиз сразу появляется в списке на экране хоста, перезапуск не нужен.
Если в файле ошибка, хост увидит её под списком квизов.

```json
{
  "title": "Networking",
  "time": 20,
  "questions": [
    { "question": "Port for HTTPS?", "options": ["80", "443", "21", "22"], "correct": 1 },
    { "type": "truefalse", "question": "IPv4 has 32 bits.", "correct": true },
    { "question": "Which is a router?", "options": ["A", "B"], "correct": 0,
      "time": 15, "image": "quiz_images/router.png" }
  ]
}
```

- `correct` — номер варианта, счёт с **0** (0 = ▲, 1 = ◆, 2 = ●, 3 = ■).
- 2–4 варианта на вопрос.
- `time` у вопроса переопределяет время квиза.
- `image` — путь внутри `static/` (или полная ссылка).

## Управление игрой (хост)

- ✕ на карточке игрока — выгнать из лобби.
- ⏭ Skip — пропустить чтение вопроса или досрочно закончить ответы.
- ⟲ Lobby — остановить игру и вернуться в лобби (игроки остаются, очки сбрасываются).
- ✕ New game — закрыть игру и создать новую с новым PIN.

## Деплой (позже)

Игра хранит всё в памяти, поэтому запускать нужно **один** процесс:

```
pip install gunicorn
gunicorn -w 1 --threads 100 -b 0.0.0.0:$PORT app:app
```

Переменные окружения: `SECRET_KEY` (любая длинная случайная строка), `PUBLIC_URL`
(адрес сайта для QR, если определяется неправильно).
